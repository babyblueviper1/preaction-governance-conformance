# x402 payment-decision recompute — the real merged fixture, not a synthetic slot

[../decision-ref-recompute/](../decision-ref-recompute/) checks the thin `decision_ref` wrapper
against a real `/review` verdict proof. This example goes one layer deeper: an **x402 payment
decision**, where the artifact under the wrapper is itself a precedence-combinator over recorded
controls — `verdict = f(controls)` — so the artifact, not just its id, has to recompute.

## Provenance

`presidio-x402-decision-ref-v1.fixture.json` is generated by `presidio-hardened-x402` and merged
into [`giskard09/argentum-core#29`](https://github.com/giskard09/argentum-core/pull/29)
(2026-06-30) — the same three vectors recompute-graded live on that PR
([autogen#7353](https://github.com/microsoft/autogen/issues/7353),
[crewAI#4877](https://github.com/crewAIInc/crewAI/issues/4877)). This wires the real, now-merged
vectors in, replacing the synthetic stand-in this repo used while the upstream fixture was still
in flight.

## The shape

```
artifact_hash = sha256(JCS(payment-decision@1 content))
decision_ref  = sha256(JCS({artifact_hash, artifact_type, policy_version, verdict}))
verdict       = f(controls)   # precedence: pii -> trusted_wallet -> policy -> replay -> mpa,
                               # first-failure-wins; MPA required-but-unresolved -> REFER
```

## Three vectors, two axes

| vector | checks | expect |
|---|---|---|
| `presidio-x402-decision-001` | baseline: hash recomputes, verdict recomputes, signer independent | accept |
| `presidio-x402-decision-signer-equals-runtime` | **admission** — signer is the actor's own payment wallet (self-approval) | reject |
| `presidio-x402-decision-verdict-not-recomputable` | **recompute** — recorded `ALLOW` but `controls.policy.verdict=VIOLATION` makes `f(controls)=DENY` | reject |

The first vector's family (hash + hash-tamper) tests whether the **id** moves with its own
preimage. The negatives here test a different axis: whether the **decision itself** is entitled
to its verdict — independent of whether its hash checks out. A decision can recompute perfectly
at the hash level and still be void because it was self-signed, or because its own recorded
verdict doesn't follow from the controls it cites.
